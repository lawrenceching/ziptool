# 桌面 UI 多语言技术方案

> 状态: 已实现
> 文案: zh-HK / zh-TW / en / ru 由实现方起草 (zh-CN 沿用原有文案), 建议发布前由母语者审校
> 范围: `crates/tauri-app/ui` 桌面界面
> 相关: [ui-backend.md](ui-backend.md) (命令面与 DTO 契约)

## 1. 目标与非目标

### 目标

- 界面支持五种语言: 简体中文 (`zh-CN`)、繁体中文香港 (`zh-HK`)、繁体中文台湾 (`zh-TW`)、英语 (`en`)、俄语 (`ru`)
- 启动时按系统语言偏好自动选择; 支持手动切换并记忆选择
- 静态文案、动态状态/进度、表格徽章、密码提示、文件选择框标题、拖拽提示全部本地化
- 保持现有纯静态 UI 架构: 无前端打包器、运行时不联网、CSP 不放宽

### 非目标

- 不本地化 Rust core / Tauri 壳层返回的告警、错误原文、排除原因 (英文界面下这些详情可能仍为中文或英文)
- 不本地化 CLI 输出
- 不翻译产品名/窗口标题 `Zip Tool`
- 不处理从右到左 (RTL) 语言
- 不在应用运行期间监听系统语言变化 (下次启动或手动切换生效)

## 2. 技术选型

采用 **i18next 26.5.3 UMD 单文件**, 复制到仓库后以 `<script>` 引入。

理由:

- 成熟的插值、复数 (基于 `Intl.PluralRules`)、回退链与缺失 key 处理, 直接满足俄语 `one/few/many/other` 变格
- UMD 产物无需打包器, 与 `ui/` 纯静态架构一致
- 外部脚本受现有 CSP `default-src 'self'` 允许, 无需修改 `tauri.conf.json`

约束:

- 固定版本 `26.5.3`, 复制 `node_modules/i18next/dist/umd/i18next.min.js` 到 `ui/vendor/i18next.min.js` 并提交; 同时保留 `ui/vendor/i18next.LICENSE`
- 语言资源不以 JSON 存放: 现有 CSP 的 `connect-src` 仅放行 `ipc:`/`http://ipc.localhost`, `fetch` 本地 JSON 会被拦截; 词条改用经典脚本注册到 `window.__ZIPTOOL_LOCALES__`
- 初始化使用 `initAsync: false` 同步完成, 避免首屏闪回默认语言

`i18next.init` 关键参数:

```js
i18next.init({
  resources: window.__ZIPTOOL_LOCALES__,
  lng: initialLocale,
  fallbackLng: "en",
  supportedLngs: ["zh-CN", "zh-HK", "zh-TW", "en", "ru"],
  initAsync: false,
  returnEmptyString: false,
  interpolation: { escapeValue: false },
});
```

## 4. 语言检测与切换

### 4.1 偏好存储

- localStorage key: `ziptool.locale`
- 取值: `system` (默认) 或 `zh-CN` / `zh-HK` / `zh-TW` / `en` / `ru`
- 非法/损坏值按 `system` 处理; localStorage 不可用时静默退回 `system`, 不阻塞启动

### 4.2 启动解析顺序

1. 若 `ziptool.locale` 是受支持的具体语言 → 直接使用
2. 否则读取 `navigator.languages` (为空时回退 `[navigator.language]`)
3. 按偏好顺序逐个匹配, 第一个命中即选中
4. 全部不匹配 → `en`

单条标签匹配规则 (先做 `_` → `-` 归一, 再用 `Intl.getCanonicalLocales` 规范化, 异常时手工拆分):

| 标签特征 | 结果 |
|---|---|
| `zh` + script `Hant` + region `HK`/`MO` | `zh-HK` |
| `zh` + script `Hant` (其他 region, 含无 region) | `zh-TW` |
| `zh` + region `HK`/`MO` (无 `Hans` script) | `zh-HK` |
| `zh` + region `TW` | `zh-TW` |
| `zh` + script `Hans` (任意 region) | `zh-CN` |
| `zh` + region `SG`/`MY` 或无 script/region | `zh-CN` |
| `en` / `en-*` | `en` |
| `ru` / `ru-*` | `ru` |
| 其他 | 继续尝试下一个偏好 |

示例:

- `["zh-Hant-HK"]` → `zh-HK`
- `["zh-Hant-TW"]` → `zh-TW`
- `["zh-Hant"]` → `zh-TW`
- `["zh-Hans-HK"]` → `zh-CN`
- `["ja-JP", "en-US"]` → `en`
- `["de-DE"]` → `en`

### 4.3 手动切换

- 状态栏右侧、版本号左边放地球图标按钮 `#lang-toggle`；点击向上弹出语言菜单 `#lang-menu`
- 选项: `跟随系统` (当前语言翻译) + 五个语言的原生名称 (固定不翻译):
  `简体中文` / `繁體中文（香港）` / `繁體中文（台灣）` / `English` / `Русский`
- 选择具体语言: 写入 localStorage, `await i18next.changeLanguage(tag)`, 应用 DOM, 触发 `localechange`
- 选择 `跟随系统`: 删除具体偏好 (写 `system`), 重新按系统偏好解析并应用
- 任务运行中也可切换; 语言下拉不加入任务锁定列表

### 4.4 应用语言

- `document.documentElement.lang = 当前 locale`
- 更新所有静态 DOM 属性
- 派发 `window` 自定义事件 `localechange` (`detail.locale`), 由 `app.js` 刷新动态内容:
  - 状态栏最后一条消息
  - 表格徽章与行 aria-label
  - 密码提示
  - 确认/取消按钮文字
  - 拖拽占位文字与高亮占位

## 5. 文案组织与渲染

### 5.1 静态 DOM

支持以下属性, 由 `i18n.applyDom()` 统一处理:

- `data-i18n="key"` → `textContent`
- `data-i18n-placeholder="key"` → `placeholder`
- `data-i18n-title="key"` → `title`
- `data-i18n-aria-label="key"` → `aria-label`

注意: `<label><input>文字</label>` 这类结构必须把文字包进 `<span data-i18n="...">`, 避免设置 `textContent` 时删掉 input。涉及:

- `随机包名`
- `压缩成功后校验`
- `覆盖已有文件`

语言下拉的 `system` 选项也通过 `data-i18n` 翻译; 语言原生名称不加属性。

### 5.2 动态消息

`app.js` 的 `status()` 改为 `setStatus(key, params)`:

```js
let lastStatus = { key: "status.ready", params: {} };

function setStatus(key, params = {}) {
  lastStatus = { key, params };
  renderStatus();
}

function renderStatus() {
  const p = { ...lastStatus.params };
  if (typeof p.bytes === "number") p.bytes = fmtBytes(p.bytes);
  $("msg").textContent = t(lastStatus.key, p);
  $("msg").title = $("msg").textContent;
}
```

- 数值型字节参数存原始数字, 渲染时再格式化, 保证切换语言后数字格式同步变化
- 后端返回的错误/告警/排除原因作为 `{{error}}` / `{{first}}` 原样插入
- 任务开始/结束/取消时按状态设置按钮文字, 语言切换后重新同步

### 5.3 复数与数字格式

- 使用 i18next 的 `count` 与 `_one/_few/_many/_other` 后缀
- 中文只有 `_other`; 英文 `_one/_other`; 俄语 `_one/_few/_many/_other`
- 字节格式用 `Intl.NumberFormat(locale, { maximumFractionDigits: 2 })`, 单位走词条 (`size.gb` 等), 俄语显示 `ГБ/МБ/КБ/Б`
- 插值只用于 `textContent`, 不拼 HTML
