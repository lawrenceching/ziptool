# CI Workflow 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 GitHub Actions `CI` workflow——push/PR 触发, 5 平台(ubuntu-latest / ubuntu-24.04-arm / windows-latest / windows-11-arm / macos-latest)跑单测 + e2e + UI 测试, 另有 clippy 与 fmt 检查; 落地前先完成 lint 清零。

**Architecture:** 单 workflow(`.github/workflows/ci.yml`)三 job:`fmt`(ubuntu 快检)、`clippy`(ubuntu+windows 两矩阵, 覆盖 `cfg!(windows)` 两家族)、`test`(5 平台矩阵)。设计规格见 `_docs/ci.md`, 本计划与其一一对应(唯一细化: `cargo test --workspace` 加 `--exclude zip-tool-e2e`, 避免 e2e 跑两遍)。

**Tech Stack:** GitHub Actions; `dtolnay/rust-toolchain@stable` + `Swatinem/rust-cache@v2` + `actions/setup-node@v4`(Node 22)。

**工作分支:** `ci/bootstrap`(Task 1-4 的提交都落在它上面, Task 5 推送验证后合回 main)。

### Task 3: 新增 workflow 文件

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: 写入完整 workflow**

```yaml
name: CI

on:
  push:
  pull_request:
  workflow_dispatch:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  fmt:
    name: fmt
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt
      - name: cargo fmt --check
        run: cargo fmt --all --check

  clippy:
    name: clippy (${{ matrix.os }})
    runs-on: ${{ matrix.os }}
    timeout-minutes: 30
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, windows-latest]
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: clippy
      - uses: Swatinem/rust-cache@v2
      - name: Install Tauri dependencies (Linux)
        if: runner.os == 'Linux'
        run: |
          sudo apt-get update
          sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev libssl-dev
      - name: cargo clippy
        run: cargo clippy --workspace --all-targets -- -D warnings

  test:
    name: test (${{ matrix.os }})
    runs-on: ${{ matrix.os }}
    timeout-minutes: 45
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, ubuntu-24.04-arm, windows-latest, windows-11-arm, macos-latest]
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
      - name: Install backend tools & Tauri dependencies (Linux)
        if: runner.os == 'Linux'
        run: |
          sudo apt-get update
          sudo apt-get install -y zip unzip p7zip-full libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev libssl-dev
      - name: Install 7z (macOS)
        if: runner.os == 'macOS'
        run: |
          brew install sevenzip
          ln -sf "$(brew --prefix)/bin/7zz" "$(brew --prefix)/bin/7z"
          7z i | head -3
      - name: Ensure 7z (Windows)
        if: runner.os == 'Windows'
        shell: pwsh
        run: |
          $seven = Get-Command 7z -ErrorAction SilentlyContinue
          if (-not $seven) {
            Write-Host "7z not found, installing via chocolatey"
            choco install 7zip -y --no-progress
            $env:PATH = [Environment]::GetEnvironmentVariable('Path', 'Machine') + ';' + $env:PATH
            $seven = Get-Command 7z -ErrorAction SilentlyContinue
          }
          if (-not $seven) { Write-Error "7z unavailable after install"; exit 1 }
          Write-Host "7z -> $($seven.Source)"
      - name: Rust unit tests (workspace, excl. e2e)
        run: cargo test --workspace --exclude zip-tool-e2e
      - name: E2E tests
        run: cargo test -p zip-tool-e2e
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: crates/tauri-app/package-lock.json
      - name: UI unit tests
        working-directory: crates/tauri-app
        run: npm ci && npm test
```

落地修订(质量审查): 两处 rust-cache 加 cache-on-failure: true; 顶层 permissions: contents: read。

要点(实现时自查):
- `dtolnay/rust-toolchain` 默认 minimal profile, rustfmt/clippy 必须显式 `components:`;test job 不需要
- `--exclude zip-tool-e2e` 防止 e2e 在 workspace 步骤先跑一遍、下一步再跑一遍
- macOS 的 `7zz → 7z` 软链是 e2e 的硬依赖(sevenzip 公式不带 `7z` 命令名), 软链后 `7z i` 打印版本确认
- Windows 的 choco 兜底分支里手动合并 Machine PATH, 保证本 step 内立即可见

- [ ] **Step 3: 若有失败——按失败点修 ci.yml 后重推**

已预案的失败模式与修法:
- 某平台找不到 `7z`:看该平台 "Install/Ensure 7z" step 日志, 补对应安装源(如 choco 失败改 winget 或下载 7zr.exe)
- `windows-11-arm` 上 tauri-app 编译失败(MSVC ARM64 组件缺失):把该平台从 test 矩阵的 tauri 覆盖中降级——`cargo test --workspace --exclude zip-tool-e2e --exclude zip-tool-tauri`, 降级时在该 step 加 `if: matrix.os != 'windows-11-arm'` 的旁路写法(复制一份 step 加条件)
- `ubuntu-24.04-arm` apt 某包不存在:对照 `apt-cache search` 结果替换包名
