文件排除

策略在压缩扫描时生效; 修改后会在关闭设置页时重新扫描当前源文件夹。被排除的条目仍会显示, 但默认不勾选。单次任务仍可在主界面的「高级」中添加自定义模式。

  • 操作系统隐藏文件

    排除操作系统隐藏属性与系统元数据文件: Windows 为隐藏属性, 以及 Thumbs.db、desktop.ini、.DS_Store、.Spotlight-V100 等系统元数据。不会按 . 前缀批量排除用户自己创建的文件。

  • 编程语言的临时文件

    排除编程语言与构建工具生成的缓存和临时文件, 例如 JavaScript 的 node_modules、Python 的 __pycache__、Java 的 .gradle 与 *.class。
